## 这套教程怎么用

这份教程是《前端工程化开发》48 学时的配套材料，按 **12 周 × 4 学时** 组织成 12 个单元，
每个单元正好一次课。教程本身可以独立自学，也可以作为课堂实训的操作手册。

::: tip 三种读法
- **课前预习**：先读本单元的“单元导学”和知识点小节，把示例跑一遍，带着问题进课堂。
- **课中动手**：直接翻到本单元对应的案例与练习，把实训任务做完。
- **课后复习**：看“常见坑”和“课后练习”自测，答不上来的地方再回到正文。
:::

## 综合项目：校园活动服务平台

项目取“活动发布 → 报名审核 → 场次安排”这条主线，做管理端。规模控制在 12 周内能完成的范围：
3 个业务页面、1 个登录入口、1 个数据看板，两个角色（组织者、审核员）。

选这个场景的理由很直接 —— 你就是这个场景的用户，需求不需要解释，精力可以放在工程化本身；
而它天然带着状态流转、时段冲突、名额联动、角色权限这些能真正练手的点。

## 课程用到的技术

| 类别 | 选型 | 说明 |
| --- | --- | --- |
| 运行时 | Node.js 22 LTS | 前端工具链的运行基础 |
| 包管理 | pnpm | 磁盘占用小、安装快，锁文件严格 |
| 构建 | Vite | 开发态按需编译，生产态打包 |
| 框架 | Vue 3（组合式 API） | 全程 `<script setup>`，不用选项式写法 |
| 路由 | Vue Router 5 | 嵌套路由、懒加载、导航守卫 |
| 状态 | Pinia 4 | 组合式写法，按业务模块拆分 |
| 请求 | axios | 实例封装 + 双拦截器 |
| 规范 | ESLint + Prettier + Stylelint | 编辑器联动 + 提交钩子双重拦截 |

具体版本号见 [工具链与版本清单](/appendix/tools)。
