## 从上一单元留下的问题说起

[单元 9](/unit09/) 结束时，你已经做完了登录鉴权：路由能拦人，没登录会被挡到登录页，
登录成功后能回到原来想去的地址。但如果你真的动手写过，会发现有几个地方很别扭：

- 登录成功后拿到的 token，你存在哪里？存在 `localStorage` 里，然后组件里到处 `localStorage.getItem('token')`？
- 顶部导航栏要显示当前用户名，这个数据从哪来？是登录页把它通过 props 一路传下去的？
- 用户点了退出，除了清掉 token，还有什么要一起清？好几个页面里缓存的用户信息怎么办？
- 活动列表页要调接口，每个页面都写一遍 `axios.get(...)`，地址、超时、错误提示各写各的？

这四个问题，前三个属于**全局状态该放在哪**，第四个属于**请求该怎么发**。
它们正是这个单元要解决的两件事。

::: tip 一个单元解决一类问题
- **全局状态**：多个不相邻的页面都要用的数据（登录用户、权限、全局提示）交给 Pinia。
- **数据请求**：所有接口调用统一走一个封装好的请求层，组件里只调用函数、不碰地址。
:::

## 与单元 9 的衔接：第 10 周的阶段性任务

这个单元不是孤立的。**本单元与单元 9 一起，构成第 10 周的阶段性任务** ——
把路由与状态接起来，跑通一条完整的鉴权链路：

1. **未登录被拦**：用户直接访问 `/activities`，路由守卫发现没有登录凭证，跳转到登录页，
   并把原本要去的地址记下来。
2. **登录后回原地址**：用户登录成功，状态模块写入 token 与用户信息，
   路由跳回当初记下的 `/activities`，这次守卫放行。
3. **退出后再次被拦**：用户点退出，状态模块清空登录信息并清掉持久化数据，
   再访问 `/activities` 时又被拦回登录页。

这条链路的每一环都同时用到路由和状态：**路由负责"能不能进"，状态负责"记不记得我是谁"**。
少任何一半都跑不通。做完这个单元，第 10 周的任务才算完成。

::: warning 这次课最容易出问题的三个地方
1. **在模块顶层调用 `useAuthStore()`** —— 会报 "getActivePinia() was called but there was no active Pinia"。
   必须在函数内部调用，原因见 [10.2](/unit10/02-pinia-basics#跨模块调用怎么写)。
2. **拦截器里直接 `window.location.href = '/login'`** —— 会整页刷新，丢掉当前路由和已填表单。
   正确做法是用 router 实例跳转，见 [10.4](/unit10/04-request-layer#401-怎么处理)。
3. **把整个 store 都持久化** —— 把加载态、错误信息也写进 `localStorage`，
   刷新后页面带着一个永远转不完的圈。见 [10.3](/unit10/03-persist)。
:::

## 这个单元的产出

按课程要求，这次课交两样东西：

**一、登录态状态模块**

| 项目 | 要求 |
| --- | --- |
| 状态字段 | token、用户基本信息（用户名、角色）、加载态、错误信息 |
| 动作 | 登录、退出、恢复登录态（从持久化读取）、刷新用户信息 |
| 持久化 | **只持久化 token 与用户基本信息**，不持久化加载态与错误信息 |
| 与路由的关系 | 路由守卫从状态模块读登录判断，不再直接读 `localStorage` |

**二、请求层封装**

| 项目 | 要求 |
| --- | --- |
| 实例 | 统一的基础地址与超时，基础地址从环境变量读 |
| 请求拦截器 | 从状态模块取 token 注入请求头 |
| 响应拦截器 | 业务状态码判定、`401` 跳登录、其他错误统一提示 |
| 接口文件 | 按业务模块拆分，`src/api/activity.js`、`src/api/signup.js` 各自独立 |
| 组件 | **组件里不出现任何接口地址**，只调用 `api/` 导出的函数 |

::: details 一份合格的请求层目录长什么样
```text [src/]
src/
├── api/
│   ├── request.js         axios 实例与拦截器
│   ├── activity.js        活动相关接口
│   ├── signup.js          报名审核相关接口
│   └── auth.js            登录相关接口
├── stores/
│   ├── auth.js            登录态模块
│   └── activity.js        活动列表状态模块
└── views/
    └── ActivityListView.vue   组件里只 import 函数，不写地址
```
判断标准：把 `src/api/` 里的地址全部改一遍，`views/` 里一个字都不用动。
:::
